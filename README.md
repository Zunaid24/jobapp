# JobApp

Job discovery and application tracking platform.

## Planned stack

- Next.js
- TypeScript
- Supabase
- Apify
- Gemini API
- Gmail OAuth

## Planned features

- Goa / Remote job discovery
- Remote jobs limited to 20 results per day
- Daily Apify job collection
- Gemini-powered job analysis and personalization
- Job/application tracker
- Personalized application emails
- Gmail OAuth with CV attachment

## Local setup

1. Install dependencies.
2. Copy `.env.example` to `.env.local`.
3. Add the required API credentials.
4. Run the development server.

The application code will be added in subsequent commits.
